# v0.2.3 — 초과 주유 즉시 실패

2026-10-13, Unity 6000.6.0f1.

- 허용 상한을 넘는 순간 공급·입력을 차단하고 초과 실패 및 −80점을 한 번만 기록합니다. 정상 완료는 기존처럼 손을 뗀 상태에서 압력이 차량 저항 이하로 내려가면 판정합니다.
- 손을 뗀 뒤 잔류 주유, 시간 초과 감압, 영업 마감 중 초과도 즉시 종료합니다. 복합 실패 원인은 기록하지만 감점을 합산해서 중복 적용하지 않습니다.
- 기존 허용 오차 `min(5 L, 목표×20%)`를 유지합니다. 상한과 같은 양은 허용합니다. 적분으로 경계 교차를 찾아 프레임 속도와 관계없이 종료합니다.

- 영업 중 최근·누적 감점, 영업 결과의 누적 감점을 표시합니다. 손실은 현재 점수이며 금액을 임의로 계산하지 않습니다. 새 영업 시 감점 집계를 초기화합니다.
- 초과 경계의 미세한 양이 반올림되어 정상처럼 보이지 않도록 `>상한`으로 표시합니다. 기록에는 실제 주유량을 보관합니다.
